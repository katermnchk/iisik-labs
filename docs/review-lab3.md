# Ревью готовности ЛР3

Проверяемый проект: iisik-lab3, версия только чтения. Требования ЛР3 закрыты: семь приложений и contracts; шесть собственных БД; JPA-модели/репозитории/ReadService; Flyway и seeds; восемь Query; шесть интерфейсов и mock-реализации без сетевых вызовов; списки/карточки/связи/ошибки.

Исправлена ошибка: directions(activeOnly:null) разрешался SDL, но primitive boolean давал INTERNAL_ERROR. Теперь null соответствует default true. Подтверждено красным тестом до исправления, 42 зелёными JUnit и реальным HTTP после.

Исправления отчёта: ключи roles.id/users.role_id; реальные String/List<String> для UUID в Java; поведение non-null и частичного ответа; разделение BAD_REQUEST и ошибок GraphQL validation; актуальные 42/34/25 проверки; текущая среда PostgreSQL 16.15 + Flyway вместо устаревших сведений; листинги Query, DTO и конфигурации. Длинные тире в обновлённом отчёте удалены.

Границы: Gateway использует независимые JSON-снимки, изменения БД в них не появляются автоматически. Диагностический REST только проверяет БД и не вызывается Gateway. Демонстрационные токены не JWT. Реальные gRPC/Kafka/Mutation относятся к следующим работам. Фильтрация/пагинация в Java и чтение вложенных записей отдельными repository-вызовами подходят малому набору; масштабирование потребует SQL-пагинации и оптимизации запросов. БД-сервисы проверены HTTP, не отдельными JPA JUnit-тестами.

Для GitHub загружается исходный проект с .mvn и mvnw, без target, .idea, .env и локальных логов. Полные контракты будущей разработки отдельно от исполняемой SDL. Отчёт сдаётся из папки Desktop/7sem-bsuir/iisik/lab3. Оценку определяет преподаватель.
